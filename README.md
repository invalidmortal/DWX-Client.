# DWX Client

DWX Client is an independent Minecraft Java Edition launcher and Fabric client project currently under development.

## Features
- Microsoft account authentication
- Minecraft version and instance management
- Fabric mod loader support
- Modrinth mod downloads
- Floating glass-style launcher interface

## Planned Features
- Visual enhancements and performance tools
- Customizable PvP HUD
- Gameplay recording and instant replay
- Animated capes and cosmetics

DWX Client requires legitimate Minecraft Java Edition ownership and does not bypass Minecraft authentication.

**Project status:** In development. Public release not yet available.

DWX Client is an independent project and is not affiliated with Mojang or Microsoft.
